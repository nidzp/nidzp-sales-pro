# NIDZP Sales Pro

Superior sales landing page za NIDZP AI Marketing.

## Pokretanje lokalno

```bash
npm install
cp .env.example .env
# Unesi VITE_GROQ_API_KEY u .env
npm run dev
```

Otvori http://localhost:5173

## Features
- Instant demo selector za delatnosti
- Transparentne cene (600€ / 2500€)
- Nina AI chat (Groq)
- Čist, modern dizajn
